# Rotina: HOJE — o painel do dia

Monte o painel com o que existe em `20-Tarefas/`:

1. **⏰ Lembretes de hoje** — de `lembretes.md`
2. **✅ Tarefas de hoje** — de `tarefas.md`, com a data de hoje
3. **🔴 Atrasadas** — data anterior a hoje e ainda não marcadas
4. **🗂 Projetos ativos** — as pastas de `30-Projetos/`

Regras:
- Não mostre evento que já passou no dia.
- Se não houver nada em uma seção, omita a seção inteira.
- Se estiver tudo vazio, diga isso em uma frase e sugira o que fazer.
- Feche com **uma** sugestão de prioridade — não com uma lista de conselhos.
